# Feature graphic — бриф для ИИ-агента

## Задача

Сделать **2 feature graphic** для Google Play одной игры (командное угадывание слов, в духе Alias).

Игра: две команды по очереди объясняют слова. Иконка приложения — столкновение двух диалоговых облаков.

Нужны **два отдельных баннера**, не один двуязычный:

1. только английский заголовок
2. только русский заголовок

Сцена (облака, VS, удар) на обоих **одинаковая**. Отличается только нижняя строка.

---

## Технические требования Google Play

- Формат: **PNG или JPEG**
- Размер холста: **ровно 1024 × 500 px**
- Вес: до **15 MB** (цель: < 1 MB)
- Цветовое пространство: **RGB, без альфы** (непрозрачный фон до краёв)
- Не класть в `res/` и не в APK — это ассет витрины, не иконка приложения

**Куда сохранять (проект `C:\Projects\Hpg\WordGuesser`):**

| Локаль | Файл |
|---|---|
| English | `C:\Projects\Hpg\WordGuesser\store\feature-graphic-en.png` |
| Russian | `C:\Projects\Hpg\WordGuesser\store\feature-graphic-ru.png` |

Перезаписать эти два файла. Другие имена не использовать. Старый двуязычный `feature-graphic.png` не создавать.

После экспорта проверить: ширина 1024, высота 500, mode RGB.

---

## Композиция кадра 1024×500

Весь смысловой блок (иллюстрация + заголовок) — **одна группа по центру**. Поля сверху и снизу примерно равные, **36–60 px**.

Вертикально, сверху вниз:

1. **Верхнее поле** ~40–55 px пустого фиолетового фона. Ни облака, ни лучи взрыва не касаются верхнего края.
2. **Иллюстрация** (~55–60% высоты): два облака + удар + VS. Горизонтально по центру.
3. **Зазор** ~16–20 px между низом облаков и текстом.
4. **Заголовок** одна строка, по центру.
5. **Нижнее поле** ~40–55 px. Нижние выносные букв (`g`, `y`, `У`, `д`) **не обрезаны**, обводка букв не прилипает к краю.

Горизонтальные поля: иллюстрация не на всю ширину — по бокам тоже фиолетовый воздух (~80–150 px суммарно). Текст не шире ~900 px.

**Запрещено:**

- кадрировать 16:9 / 3:2 в 1024×500 через center-crop (обрезает низ или верх)
- прижимать текст к нижнему краю
- прижимать облака/лучи к верхнему краю
- огромная пустая полоса снизу при обрезанном верхе

Если исходник другого соотношения — **вписать целиком** или собрать макет сразу как 1024×500. Не резать содержимое.

## Сцена (одинаковая на EN и RU)

Фон: глубокий фиолетовый, почти плоский, лёгкий radial glow за ударом.  
Ориентир: `#16043A` / `#19013A`. Без сетки, без фото, без телефонов, без бейджей Play.

**Слева** — красное диалоговое облако (speech bubble) с хвостом к центру:

- толстая **белая** обводка
- внутри большая белая буква **A**
- облако слегка треснуто у точки удара

**Справа** — синее диалоговое облако, зеркально:

- белая обводка
- внутри большой белый **?**
- трещина у точки удара

**Центр:**

- жёлто-белый comic **starburst** (удар)
- мелкие искры, звёзды, красные/синие осколки
- поверх удара **VS** (можно `VS` или `vs`) — кремовый/белый с тёмно-фиолетовой обводкой

Смысл: две команды бьются словами, как на иконке приложения.

---

## Градиенты облаков (важно)

Заливка каждого облака — **один непрерывный гладкий градиент**, как пластиковый шар / воздушный шар.

- Красное: блик сверху-слева (светлый коралл) плавно в глубокий красный справа-снизу
- Синее: светлый циан-блик плавно в глубокий синий

**Нельзя:**

- cel-shading, постеризация, кольца и ступеньки цвета
- отдельные «слои» светлее/темнее с жёсткой границей
- полосы как у 8-bit градиента

Блик — мягкий specular, который **растворяется**, не кружок с обводкой. Если модель даёт banding — перерисовать облака векторно/кодом с radial gradient + dither, не оставлять ступеньки.

## Текст

Только одна строка заголовка, язык файла:

- EN: `Guess the Word`
- RU: `Угадай слово`

Шрифт: жирный rounded sans (как Segoe UI Bold), цвет крем/белый `#F6F0E6`, тёмно-фиолетовая обводка `#12082A`.

Не писать на одном баннере оба названия.  
Не дублировать слоган, «Alias», «#1», «Free», рейтинг, UI телефона.

`A`, `?`, `VS` — часть иллюстрации, не заголовок. Их оставить на обоих файлах.

## Стиль

Чистый 2D mobile-game key art, высокий контраст, без фотореализма. Читается в маленьком превью витрины: облака крупные, VS крупный, заголовок крупный.

Референс настроения: иконка приложения в `app/src/main/res/drawable-nodpi/ic_launcher_foreground.png` (два облака A vs ?, удар, фиолетовый фон). Feature graphic — **широкая версия той же идеи**, не копия иконки 1:1 и не вставка квадратной иконки на баннер.

---

## Чего не делать (уже ломалось)

1. Генерировать 16:9 или 3:2 и center-crop до 1024×500 — обрезается «Guess the Word» / «Угадай слово».
2. Спасая низ, кропать только сверху — обрезаются VS и верхушки облаков, снизу пустота.
3. Писать оба языка на одном баннере.
4. Оставлять ступенчатый градиент на облаках.
5. Класть файлы в `mipmap` / `drawable`.

## Критерии готовности

- [ ] Ровно 1024×500, RGB PNG
- [ ] Два файла по путям выше
- [ ] EN-файл: только `Guess the Word`; RU-файл: только `Угадай слово`
- [ ] Облака, A, ?, VS, удар целиком в кадре
- [ ] Заголовок целиком, включая низ букв и обводку
- [ ] Поля сверху и снизу сопоставимы, нет «прилипания» к краям
- [ ] Заливка облаков без видимых колец/ступенек
- [ ] Нет макетов устройств, бейджей стора, водяных знаков
